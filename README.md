# Customer_Behavior_Analysis
Customer Behavior Analysis is a data analytics project that analyzes customer purchasing patterns, spending habits, subscription status, discounts, and customer segments. The project uses SQL, Python, and Power BI to identify trends, understand customer behavior, measure revenue, and generate actionable insights for better business decisions.

# Customer Behaviour Analysis 📊

## Overview

**Customer Behaviour Analysis** is an end-to-end Data Analytics project that analyzes customer purchasing patterns, spending behavior, discounts, subscriptions, and customer segments.

The project demonstrates the complete analytics workflow from **raw data to business insights** using Python, SQL, and Power BI.

## 🎯 Objectives

- Analyze customer purchasing behavior
- Clean and prepare raw data
- Perform Exploratory Data Analysis (EDA)
- Solve business questions using SQL
- Identify customer segments and trends
- Build an interactive Power BI dashboard
- Generate actionable business insights

## 🗂️ Dataset

The dataset contains customer-related information such as:

- Customer ID
- Age and demographics
- Purchase Amount
- Previous Purchases
- Discount Applied
- Subscription Status
- Customer Segments
- Purchase-related information

## 🛠️ Tools & Technologies

- **Python** – Data analysis and cleaning
- **Pandas & NumPy** – Data manipulation
- **Matplotlib & Seaborn** – Visualization
- **PostgreSQL / MySQL / SQL Server** – SQL analysis
- **Power BI** – Dashboard and reporting
- **Gamma** – Presentation
- **GitHub** – Project documentation

## 🔄 Project Workflow

**Dataset → Python → EDA → Data Cleaning → SQL Analysis → Power BI Dashboard → Report → Presentation → Business Insights**

### 1. Python & EDA

- Loaded the dataset using Pandas
- Checked rows, columns, and data types
- Analyzed missing and duplicate values
- Identified patterns and trends
- Created visualizations for better understanding

### 2. Data Cleaning

- Handled missing values
- Removed duplicates
- Corrected data types
- Standardized categorical values
- Checked inconsistent data

### 3. SQL Analysis

Used SQL to answer business questions related to:

- Customer segmentation
- Purchase behavior
- Revenue
- Discounts
- Subscription status
- Customer spending
- New, Returning, and Loyal customers

SQL concepts used:

`GROUP BY` | `CASE` | `JOIN` | `CTE` | `Subqueries` | `Aggregate Functions` | `Window Functions`

### 4. Power BI Dashboard

Created an interactive dashboard to track:

- Total Customers
- Total Revenue
- Average Purchase Amount
- Customer Segments
- Subscription Analysis
- Discount Analysis
- Purchase Trends

## ▶️ How to Run

### Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy
```

### Run the Project

1. Open the Python notebook.
2. Load the customer dataset.
3. Perform EDA and data cleaning.
4. Load the cleaned data into PostgreSQL/MySQL/SQL Server.
5. Execute the SQL queries.
6. Open the Power BI `.pbix` file.
7. Refresh the data and explore the dashboard.
