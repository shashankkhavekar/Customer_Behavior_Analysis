# Customer_Behavior_Analysis
Customer Behavior Analysis is a data analytics project that analyzes customer purchasing patterns, spending habits, subscription status, discounts, and customer segments. The project uses SQL, Python, and Power BI to identify trends, understand customer behavior, measure revenue, and generate actionable insights for better business decisions.

# 📊 Data Analytics Project

## Overview

This project demonstrates an end-to-end **Data Analytics workflow**, from data loading and cleaning to SQL analysis, Power BI dashboard creation, reporting, and presentation.

## 🎯 Objectives

- Load and analyze data using Python
- Perform EDA and data cleaning
- Write SQL queries for business analysis
- Create an interactive Power BI dashboard
- Prepare a report and Gamma presentation
- Generate meaningful business insights

## 🛠️ Tools Used

- **Python** – Pandas, NumPy, Matplotlib, Seaborn
- **SQL** – PostgreSQL / MySQL / SQL Server
- **Power BI** – Dashboard and visualization
- **Gamma** – Presentation
- **Excel** – Data support

## 🔄 Workflow

```text
Dataset → Python → Data Cleaning → EDA → SQL → Power BI → Report → Presentation
```

## 📂 Dataset

The dataset was cleaned and analyzed to identify trends, patterns, customer behavior, and important business metrics.

## 📊 Dashboard

An interactive Power BI dashboard was created with:

- KPI Cards
- Charts
- Filters & Slicers
- Business Performance Metrics

## 📈 Results

The analysis identified key trends, performance indicators, customer patterns, and business insights to support data-driven decisions.

## ▶️ How to Run

1. Clone the repository.
2. Open the Python notebook.
3. Install required Python libraries.
4. Run data cleaning and EDA.
5. Load the cleaned data into PostgreSQL/MySQL/SQL Server.
6. Run the SQL queries.
7. Open the Power BI `.pbix` file.
